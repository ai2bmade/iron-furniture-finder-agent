description: 링크드인에서 긁어온 "구매담당자(Buyer/Purchasing/Sourcing/Procurement)" 검색결과 PDF 하나를 입력받아, 인물 단위로 파싱 → 중복 제거 → 소속회사를 고유 리스트로 추출 → 회사별 조사(유형·규모 판별)를 병렬 리서치 에이전트로 수행 → 등급(A~X) 부여 → 경쟁사 매핑 → 원문 한글번역까지 반영한 엑셀 리스트를 만들고, 회사 중심으로 산업 구조를 계층화한 Full Report(MD)까지 작성하는 스킬. 산업마다 "누가 진짜 구매자이고 누가 경쟁사인지"의 구조가 다르므로, 시작 전 항상 사용자의 비즈니스 방향(완제품 브랜드 수출인지, 산업재/장비 수출인지 등)을 확인해 등급 로직의 방향을 그 산업에 맞게 다시 세운다 — 소비재(예: 뷰티)에서는 "재판매하는 유통업체"가 최우선이고 "자사 브랜드만 파는 제조사"가 비타겟이지만, 산업재(예: 전기장비)에서는 정반대로 "장비를 사서 직접 쓰는 최종수요자"가 최우선이고 "동일 장비를 만드는 제조사"는 오히려 경쟁사다.

# 수출바이어파인더 스킬

## 1. 기본 정보
- 스킬 이름: 수출바이어파인더 (Export Buyer Finder)
- 한 줄 요약: 링크드인 구매담당자 검색결과 PDF를 받아 인물 파싱 → 회사 단위 웹조사 → "유통 채널 규모"와 "완제품 재판매 여부" 기준의 A/B/C/D/X 등급 분류 → 경쟁사 매핑 → 한글 번역이 담긴 엑셀 산출물과, 회사를 계층 구조로 정리한 산업분석 Full Report(MD)를 함께 만든다.
- 카테고리: 해외영업 / 바이어(Buyer) 발굴 / 무역
- 버전: v2.0
- 배경: 특정 산업(뷰티) 하나를 파일럿으로 완성한 뒤, 같은 프로세스를 다른 산업(전기장비, 패션, 식품 등)에도 재사용해 "모든 산업의 Finder Agent"로 확장하는 것이 최종 목표다. v1.0은 뷰티(소비재·완제품 브랜드 수출) 전용이었고, v2.0에서 "산업 프로파일" 개념을 도입해 전기장비(산업재·장비 수출) 사례로 일반화했다.

## 0. 산업 프로파일 — 다른 산업에 적용하기 전에 반드시 먼저 정의할 것

이 스킬의 핵심은 파싱·엑셀·리포트 만들기가 아니라 **"이 산업에서 누가 진짜 구매자이고 누가 경쟁사인가"를 올바르게 세우는 것**이다. 산업이 바뀌면 등급의 방향 자체가 뒤집힐 수 있으므로, 매번 아래 3개 그룹을 사용자에게 확인한 뒤 시작한다.

| 그룹 | 정의 | 뷰티(소비재·완제품브랜드) 사례 | 전기장비(산업재·장비) 사례 |
|---|---|---|---|
| **① 최우선 구매력 그룹** | 완제품/장비를 사서 (재판매하든 직접 쓰든) 실제 채택 결정을 내리는 조직. 규모가 클수록 상위 등급. | 완제품을 매입해 매대에 올리는 **유통·리테일러**(백화점, 이커머스, 드럭스토어 등) | 장비를 사서 **자기 인프라에 직접 설치·운용**하는 **최종수요자**(전력회사, 유틸리티, 전력협동조합, 지방정부 전기부서, 발전소·변전소·배전소 운영사) |
| **② 중간 유통·무역상 그룹** | 재판매를 본업으로 하되 ①보다 결정권·물량이 작은 중개자. | 소싱에이전시, 소형 무역상 | 전기장비 유통상, 조달대행업체, 전기자재상(Electric Supply) |
| **③ 경쟁사 그룹 (비타겟)** | 사용자와 같은 것을 만들어 파는 주체 — 아무리 크고 직급이 높아도 등급을 최하위로 고정. | **자사 브랜드만 제조판매하는 브랜드사**(P&G, 로레알 등 — 완제품을 "사는" 게 아니라 원료만 삼) | **동일 장비를 만드는 제조사**(Switchgear·Circuit Breaker 제조업체 — 사용자의 직접 경쟁사) |

이 표에서 보듯 **뷰티에서는 ①이 "재판매"이고 ③이 "자사생산"이지만, 전기장비에서는 ①이 "직접사용(최종소비)"이고 ③이 여전히 "생산"** — 즉 ③(제조사)은 산업이 바뀌어도 대체로 비타겟/경쟁사 위치를 유지하는 반면, ①의 정의(재판매자인지 최종사용자인지)는 산업마다 반드시 새로 확인해야 한다. 새 산업에 이 스킬을 적용할 때는 작업을 시작하기 전에 사용자에게 "이 산업에서 ①/②/③에 해당하는 조직 유형이 각각 무엇인지"를 명시적으로 확인하거나, 사용자가 이미 말해준 우선순위 문장(예: "전력회사·유틸리티가 우선이고 제조업체는 경쟁사다")에서 이 3그룹을 정확히 추출해 등급 로직에 반영한다.

## 2. 호출 방식
- 직접 호출 명령어: /수출바이어파인더
- 자동 인식 키워드 (사용자가 아래 표현을 언급하면 스스로 이 스킬을 찾아 써야 함)
  1. "이 PDF에서 바이어 리스트 뽑아줘" / "구매담당자 리스트 분류해줘"
  2. "링크드인에서 긁어온 사람들 등급 매겨줘"
  3. "이 산업 바이어/유통사 지도 만들어줘"
  4. "잠재 buyer/seller/partner 정리해줘" (사용자가 원래 표현한 1단계 과제)
- 이 스킬을 쓰면 안 되는 상황
  - 입력이 "구매담당자" 검색결과가 아니라 다른 직군(예: 마케터, 디자이너) 리스트인 경우 — 등급 로직(구매 vs 경쟁 자체구매) 자체가 무의미해짐
  - "0. 산업 프로파일"의 ①/②/③ 그룹을 확인하지 못한 채로 시작하는 경우 — 산업이 바뀌면 등급의 방향 자체가 뒤집힐 수 있으므로(예: 뷰티는 유통업체가 A, 전기장비는 최종수요자가 A이고 유통업체 격인 무역상은 오히려 중간등급), 시작 전에 반드시 사용자의 비즈니스 방향과 이 3그룹을 먼저 정의한다
  - PDF가 링크드인 검색결과 스크린샷 캡처본이 아니라 정식 프로필 export인 경우 — 파싱 정규식(이름 • 연결촌수, Connect/Message/Follow/View 버튼 경계)이 다를 수 있어 파서를 먼저 점검해야 함

## 3. 입력 파라미터
- 필수 입력값
  - 링크드인 "구매담당자" 검색결과 PDF 경로 (Sales Navigator 또는 일반 검색결과를 인쇄한 PDF, 카드 형태로 이름/직함/위치/Connect버튼/소개문단이 반복되는 구조)
  - 사용자의 비즈니스 방향과 "0. 산업 프로파일"의 ①최우선구매력/②중간유통/③경쟁사 그룹 정의 — 등급 로직의 방향을 결정하는 가장 중요한 값이므로 없으면 반드시 먼저 질문한다(단, 사용자가 이미 우선순위를 문장으로 말해준 경우는 그 문장에서 3그룹을 추출해 확인 질문을 생략할 수 있다)
- 선택 입력값
  - 등급 단계 수와 이름 (기본값: A/B/C/D/X 5단계 — 글로벌대형유통/중간유통/소형유통/브랜드사제조사/불명확)
  - 결과 저장 위치 (기본값: 입력 PDF와 같은 폴더)
  - 산업분석 Full Report 작성 여부 (기본값: 작성함)
- 입력값이 여러 개일 때 우선순위 처리 규칙
  1. 사용자가 이번 요청에서 명시적으로 준 등급 정의(예: "대형 리테일 체인은 A, 자사 브랜드만 파는 대형 브랜드사는 D")를 최우선으로 따르고, 임의로 다른 기준을 적용하지 않는다.
  2. PDF 파싱 결과와 실제 페이지 수(예: "• 1st/2nd/3rd+" 등장 횟수와 Connect/Message/Follow/View 버튼 등장 횟수)가 불일치하면, 임의로 넘어가지 않고 반드시 원인(페이지 경계에서 잘린 항목, 이미지로만 존재하는 이름 등)을 찾아 수동 보정한다.
  3. 회사명이 여러 표기(약칭/공식명/현지어)로 등장하면 하나의 표준 표기로 통일해 고유회사 리스트를 만든다.

## 4. 작업 절차
1. **PDF 텍스트 추출**: pdfplumber로 전체 페이지 텍스트를 추출한다(레이아웃 보존 필요시 `layout=True` 옵션 병행). Windows 환경에서 시스템 python이 여러 개 설치되어 있을 수 있으니(`py -0p`로 확인), pdfplumber/pandas/openpyxl이 설치된 인터프리터를 명시적으로 지정해 사용한다.
2. **인물 단위 파싱**: `이름 • 1st/2nd/3rd+` 패턴을 항목 시작 경계로, `Connect|Message|Follow|Pending|Following|View` 를 버튼 경계로 잡아 이름/직함(버튼 이전 줄들)/위치(버튼 직전 한 줄)/소개문단(버튼 이후, "mutual connection"이나 "X followers" 줄 이전까지)으로 분리한다. "• Nth" 등장 횟수와 버튼 등장 횟수가 일치하는지 반드시 대조한다.
3. **파싱 오류 보정**: 마지막 페이지 등에서 이름 텍스트 자체가 이미지 처리되어 못 읽히는 경우가 있다("이름미상"으로 표기하고 진행). 소개문단이 다음 항목과 뒤섞여 파싱된 경우 원본 페이지를 다시 열어 손으로 분리한다.
4. **중복 제거**: (이름, 소개문단) 조합이 완전히 같은 행을 제거한다.
5. **고유 회사 리스트 추출**: 소개문단에서 "at 회사명" 패턴 등으로 회사명을 뽑아 정리한다. 보통 인원의 60~75% 정도가 고유 회사 수가 된다.
6. **회사별 조사**: 고유 회사가 많을 경우(대략 100개 이상) 두 가지 방식을 산업 특성에 맞게 섞어 쓴다.
   - **소비재/브랜드 산업**(회사명만으론 정체를 알 수 없는 경우가 많음 — 예: 뷰티): 확신 있게 아는 대기업/유명 체인은 직접 작성하고, 생소한 나머지는 25~30개씩 묶어 general-purpose 에이전트를 여러 개 백그라운드로 동시에 띄워 웹서치시킨다. 각 에이전트에게 "업종설명 1문장 / 규모(판단근거) / 채널유형" 마크다운 표를 반환하도록 요청한다.
   - **산업재/공공기관 산업**(회사·기관명 자체에 유형이 드러나는 경우가 많음 — 예: 전기장비: "Electric Cooperative", "Power & Light", "Public Utility District", "Municipal Utilities", "Switchgear", "Circuit Breaker" 등): 회사명·직함 키워드 기반 규칙(rule-based) 분류를 1차로 적용해 웹조사 부담을 줄이고, 애매하거나 처음 보는 키워드가 붙은 회사만 추가로 조사한다. 이 경우 인원 수가 많으면(300명 이상) 분류·번역 작업 자체를 general-purpose 에이전트 여러 개에 병렬로 위임하되, 프롬프트에 ①/②/③ 그룹 정의와 판별 키워드 예시를 명시적으로 포함해 임의 판단 여지를 최소화한다.
7. **등급 로직 적용**: "0. 산업 프로파일"에서 정의한 ①/②/③ 그룹을 아래 틀에 대입한다.
   - A = ①그룹의 대형(다국적/수백만 고객·수백개 지점 규모 이상)
   - B = ①그룹의 중소형(지역·지방 단위)
   - C = ②그룹(중간 유통·무역상) — 필요시 규모별로 세분(대형 무역상은 B로 올릴 수 있음)
   - D = ③그룹(경쟁사) — **회사 규모·직급과 무관하게 무조건 D로 하향**한다. 소비재에서는 "자사 브랜드만 파는 브랜드사"였고, 산업재에서는 "동일 제품을 만드는 제조사"이지만, 두 경우 모두 사용자의 완제품/장비를 사서 채택할 조직이 아니기 때문이다.
   - X = 정보 확인 불가, 카테고리 자체가 무관한 업종, 또는 **구매 결정권이 없는 인접 조직**(예: 산업재의 경우 규제기관·공공위원회, 업계 협회/단체, 순수 엔지니어링 컨설팅펌처럼 실제 조달 예산을 집행하지 않는 곳)
   - 판단이 애매한 회사(예: 대형 유통사 소속이지만 직무가 "원자재 조달"인 경우, 전기공사업체처럼 시공은 하지만 장비를 대량구매하는지 불확실한 경우)는 한 단계 보수적으로(낮게) 매기고 회사소개 문구에 애매함을 남겨 사용자가 2단계에서 확인하게 한다.
8. **경쟁사/유사업체 매핑**: 회사별로 업계에서 알려진 동종 경쟁사·유사업체를 3~5개 이름만 나열한다. 확신이 없는 소형 회사는 "지역 소형 업체 다수(개별 특정 어려움)"처럼 정직하게 표기하고 지어내지 않는다.
9. **원문 한글 번역**: 소개문단 원문을 통째로, 요약이 아니라 완전한 한글 번역으로 옮긴다(짧은 "한글요약" 컬럼과는 별도로 둔다).
10. **엑셀 생성**: pandas + openpyxl로 등급별 색상(조건부서식), 헤더 고정, 자동필터, 등급 오름차순 정렬을 적용한 결과 시트와, 등급별/유형별 인원수 집계 시트, 등급 정의를 설명하는 "등급기준" 시트를 함께 만든다. 컬럼 순서는 사용자 요청에 맞춰 유연하게 조정하되(예: "H열과 I열 사이에 경쟁사 열 삽입"), 몇 번째 열이 무엇인지 사용자와 같은 알파벳 기준으로 소통한다.
11. **산업분석 Full Report(MD) 작성**: "9. 예시"의 구조를 참고해, 사람이 아니라 **회사**를 중심으로 계층 구조 리포트를 작성한다(지역별 대형 그룹 → 업태별 채널 → 소형 유통·소싱에이전시 → 브랜드사·제조사(비타겟, 이유 설명) → 카테고리 불일치 순). 각 그룹마다 "왜 우선 접근해야 하는지 / 왜 접근하면 안 되는지"를 서술한다.

## 5. 출력 형식
- 엑셀 파일 (.xlsx), 시트 3개 이상: 전체리스트 / 요약(등급×유형 집계) / 등급기준(정의 설명)
  - 전체리스트 컬럼(예시, 사용자 요청에 따라 조정 가능): No / 등급 / 유형 / 이름 / 한글요약 / 직함(영문) / 소속회사 / 회사소개 / 경쟁사·유사업체 / 위치 / 원문설명(한글번역)
  - 등급 컬럼에는 조건부서식(등급별 배경색)을 적용한다.
  - 헤더 행 고정 + 자동필터 적용.
- 산업분석 Full Report (.md): 회사 중심 계층 구조. 사람 이름은 등장시키지 않거나 최소화하고, 회사·그룹·채널 단위로 서술한다. "왜 이 그룹을 먼저 접근해야 하는지 / 왜 이 그룹은 후순위이거나 대상이 아닌지"를 각 섹션마다 명시한다.
- 두 산출물 모두 원본 PDF와 같은 폴더에 저장하고 사용자에게 SendUserFile로 전달한다.

## 6. 자체 검증 절차 (결과를 내놓기 전에 반드시 수행)

### 검증 1: 파싱 누락/중복 확인
- "이름 • Nth" 등장 횟수와 Connect/Message/Follow/View 버튼 등장 횟수를 grep 등으로 세어 정확히 일치하는지 확인한다. 불일치하면 몇 건이 비는지, 어느 페이지인지 찾아 원인을 밝힌다.
- (이름, 소개문단) 기준 중복 건수를 세어 제거 전/후 인원수를 기록한다.

### 검증 2: 고유회사 커버리지 확인
- 등급/경쟁사 매핑 테이블에 있는 회사명 집합과, 실제 파싱된 고유회사 리스트를 비교해 누락된 회사가 없는지 코드로 대조한다. 누락이 있으면 채워 넣기 전까지 최종 파일을 만들지 않는다.

### 검증 3: 등급 극단값·경계 확인
- D등급(브랜드사)으로 분류된 회사 중 실제로는 "완제품을 매입해 재판매하는" 회사가 섞여 있지 않은지, 반대로 A/B/C(유통) 중 사실은 자사 브랜드만 파는 곳이 섞여 있지 않은지 무작위로 몇 건을 원문 소개문단과 대조해 재확인한다(예: 이번 뷰티 케이스에서 특정 대형 브랜드사 소속 인물이 처음에 "브랜드사구매"가 아닌 "리테일러바이어"로 잘못 들어갔던 사례).

## 7. 예외 처리 규칙
- 회사 정보를 웹조사로도 찾지 못한 경우: 임의로 규모나 채널유형을 추정해 단정하지 않고 X등급 또는 "정보 제한적/추정"이라고 명시한 뒤 진행한다.
- 사용자가 등급 기준을 중간에 바꾸는 경우(이번 세션처럼 3단계 → 5단계로 변경): 기존에 만든 회사별 조사 데이터(업종/규모/채널유형)는 재사용하고, 등급 매핑 규칙만 새로 적용해 처음부터 다시 조사하지 않는다.
- 컬럼 삽입/삭제 요청: "H열과 I열 사이에 넣어달라"처럼 사용자가 최종 엑셀 기준 알파벳 위치로 말하면, 그 위치가 어떤 필드 다음인지 되짚어 확인한 뒤 삽입한다(임의로 다른 위치에 넣지 않는다).
- 산업/비즈니스 방향이 불분명할 때: "이 회사가 원료를 사는지 완제품을 사는지" 애매한 소개문단이 많으면 등급을 임의로 확정하지 않고, 대표 사례 몇 건을 사용자에게 보여주며 방향을 확인한다.

## 8. 연계 가능한 다른 스킬 (향후 확장 예정)
- **유틸리티바이어소스리서치**: 이 스킬은 "이미 확보된 링크드인 PDF"에서 출발하지만, 애초에 링크드인 검색에 의존하지 않고 정부·유틸리티 공식 문서(입찰/낙찰/자본계획/승인벤더목록)에서 증거 기반으로 바이어를 처음부터 찾아내고 싶을 때는 그 스킬을 먼저 쓴다. 특히 공공/규제 대상 산업재(전력기기 등 입찰·조달 기록이 공개되는 산업)에서는 그 스킬로 만든 상위 리드를 링크드인에서 검색해 PDF로 저장한 뒤, 이 스킬로 넘겨 인물 단위 분류를 이어가는 흐름이 효율적이다.
- **리테일바잉시그널모니터링**: 뷰티 등 소비재처럼 공개 입찰이 없는 산업에서, 링크드인 검색에 의존하지 않고 수입통관데이터·벤더제출포털·바이어채용공고·IR자료 등으로 "지금 실제로 구매 의향이 있는지" 증거부터 찾고 싶을 때 이 스킬 대신 그 스킬을 먼저 쓴다. 원리는 유틸리티바이어소스리서치와 같되(증거 우선, 링크드인은 최종단계), 입찰이 없는 산업에 맞게 신호 체계가 재설계되어 있다. 산업에 "공개 입찰이 있는가"로 두 리서치형 스킬 중 하나를 고른다.
- 이 스킬의 결과물(엑셀)을 입력으로 받아 이어질 다음 단계(사용자가 밝힌 전체 로드맵):
  1. (이 스킬, 또는 유틸리티바이어소스리서치/리테일바잉시그널모니터링) 잠재 buyer/seller/partner 등급 분류
  2. 상세정보·연락처(이메일 등) 조사 스킬 — 아직 미구현
  3. 컨택 메시지 작성 스킬 — 아직 미구현(단, 유틸리티바이어소스리서치·리테일바잉시그널모니터링의 Buying Signal/Evidence Summary를 확보한 경우 메시지에 인용하면 설득력이 높아짐)
  4. 관계 유지·네트워크 관리 스킬 — 아직 미구현
- 산업분석 Full Report는 다른 산업(패션, 식품, 리빙 등)에 이 스킬을 재적용할 때 "채널 계층 구조를 어떻게 나눌지"에 대한 템플릿으로 참고할 수 있다.

## 9. 예시

### 예시 A — 뷰티 산업 (소비재·완제품브랜드 수출, "Beuty acquisition purachsing buying .pdf" 81페이지)
- 입력: 링크드인 구매담당자 검색결과 PDF(81페이지, "이름 • Nth" 248회 등장 = 인물 248명)
- 파싱 결과: 248명 중 (이름,소개문단) 완전중복 6명 제거 → 244명 고유, 마지막 페이지 2명은 이름 이미지 누락으로 "이름미상" 처리
- 고유회사: 172개 → 직접 아는 대기업/체인 ~75개는 직접 작성, 생소한 ~90개는 3개 에이전트(각 25~30개)를 병렬로 백그라운드 실행해 웹조사(회사 단위 조사)
- 산업 프로파일: ①=완제품을 매입하는 유통·리테일러, ②=소싱에이전시/소형무역상, ③=자사 브랜드만 파는 브랜드사(P&G·로레알 등, OEM 포함)
- 등급 결과: A(글로벌대형유통) 111명 / B(중간유통) 30명 / C(소형유통·무역상) 27명 / D(브랜드사·제조사) 66명 / X(카테고리불일치) 10명
- 검증 3에서 발견한 재분류 사례: 특정 브랜드사(계열 서브 브랜드 포함) 소속 구매담당 3명이 처음에는 "리테일러바이어"로 분류돼 있었으나, 실제로는 자사 브랜드만 제조판매하는 회사임을 확인하고 D등급으로 재분류함
- 최종 산출물: 엑셀 1개(No~원문번역 11개 컬럼, 등급기준 시트 포함) + 산업분석 Full Report(MD, 회사를 지역별 대형그룹→채널별→소형무역상→브랜드사(비타겟)→카테고리불일치 순으로 계층화) + 디자인 입힌 PDF본(HTML→Edge headless 인쇄)

### 예시 B — 전기장비 산업 (산업재·장비 수출, "...DC Switchgear, Circuit Recloser, Circuit Breaker, Solid Dielectric Ring.pdf" 130페이지)
- 입력: 링크드인 구매/조달 담당자 검색결과 PDF(130페이지, "이름 • Nth" 470회 = 인물 470명)
- 파싱 결과: 470명 중 완전중복 4명 제거 → 466명 고유. 소개문단 자체가 원본에 없는 인물 9명은 "(소개문단 미기재)"로 표기
- 산업 프로파일(사용자가 문장으로 미리 제시): ①=장비를 사서 직접 쓰는 최종수요자(전력회사·유틸리티·전력협동조합·지방정부전기·발전소·변전소·배전소), ②=전기장비 유통·무역상, ③=**동일 장비를 만드는 제조사(경쟁사)** — 뷰티와 정반대로 "재판매"가 아니라 "직접사용"이 최우선 그룹이 됨
- 회사조사 방식: 뷰티와 달리 기관명 자체에 유형이 드러나는 경우가 많아(Electric Cooperative, Public Utility District, Switchgear 등) 회사 단위 웹조사 대신 **인물 단위 규칙기반 분류를 general-purpose 에이전트 4개(각 115~117명)에 병렬 위임**해 분류+한글번역을 동시에 처리
- 등급 결과: A(대형 최종수요자, 다국적 대형 전력회사·국영 전력공사·초대형 산업체 등) 64명 / B(중소형 최종수요자, 지역 협동조합·지자체 전기부서 등) 137명 / C(유통·무역상) 14명 / D(제조사·경쟁사, 스위치기어 제조업체 다수) 178명 / X(규제기관·업계협회·엔지니어링컨설팅펌·전기공사업체 등) 73명
- 특징: 검색 키워드에 "Switchgear"가 포함되어 있어 제조사(경쟁사, D등급) 비중이 뷰티 사례보다 훨씬 높게 나옴(178/466, 약 38%) — 검색어 자체에 제품명이 들어가면 경쟁사가 대량으로 섞여 들어올 수 있다는 시사점
- 최종 산출물: 엑셀 1개(No/등급/유형/이름/한글요약/직함/소속회사/위치/원문번역, 요약·등급기준 시트 포함). 회사소개·경쟁사 매핑, 산업분석 Full Report, 디자인 PDF는 이번엔 요청받지 않아 생략(필요시 뷰티 사례와 동일한 절차로 추가 가능)
